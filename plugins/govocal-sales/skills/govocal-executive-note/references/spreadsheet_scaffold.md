# Spreadsheet scaffold — six canonical tabs

The spreadsheet always has the same six product tabs (plus an Overview/Legend tab). What varies per competitor:
- **Which rows appear** — pick from the row library below based on what the competitor actually does; drop rows that are irrelevant; add new rows when the competitor introduces a novel dimension
- **The competitor's status and details** — tailored to their docs
- **The Go Vocal details** — update any rolling stats (e.g. SMS roadmap date)

The six tabs are the canonical organising frame. Don't invent a seventh tab — instead, add categories inside existing tabs.

## Tab 0 — Overview

- Title: `Go Vocal × {Competitor} — Feature Comparison` (localised)
- Subtitle: one sentence about who this is for
- Legend (🟢 / 🟡 / 🔴)
- How-to-read section — lists the six tabs with one-line descriptions
- Honesty note in cherry italic: "Written honestly: where {competitor} does something Go Vocal doesn't yet, we say so"

## Base row library

The rows used in the Decidim spreadsheet are a strong starting point. Not every row applies to every competitor — *tailor*:

- Drop rows where the competitor has no product surface at all in that area (e.g. drop "Merging of ideas" if competitor doesn't have ideation at all).
- Add rows for things the competitor does well that we should honestly compare on (e.g. if they're known for a specific AI feature, add a row for it).
- Keep rows where the competitor genuinely beats us — those are the RED-for-GV rows that build credibility with the reader.

## Rating honesty

- Every GREEN for Go Vocal should be something we demo cleanly today.
- YELLOW is legitimate for roadmap items with a specific date (e.g. "SMS verification — Q2 2026"), or for features that exist but with caveats.
- RED on our side should name what's on the backlog if applicable — the Decidim spreadsheet does this on "Merging of ideas".
- At least 2-3 RED or YELLOW rows for Go Vocal across the whole spreadsheet. Zero is a red flag of dishonesty to the reader.
