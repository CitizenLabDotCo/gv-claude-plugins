> Source: FR Modular Proposal Template (Google Doc `1BRxIi7b5AgOg9IZ-zFZNFnA-CzBupwU-ED3aFip9zys`),

## Key lexical choices (respect these)

- **habitants** over *citoyens* for people on the platform (*citoyen* only for stats and
  set phrases like "participation citoyenne"); **collectivité(s)** for the client
  organization (also commune, municipalité, territoire); **démarche (participative)** for
  an engagement process; **contribution** as the umbrella input word; **enquête** (never
  "sondage") for surveys; **votation** for a voting exercise; **étiquette** when
  explaining tags to admins.

## Conventions

- **Vous, always**; house style narrates features with vous-imperatives ("Bénéficiez",
  "Créez"). No tutoiement.
- **Inclusive writing**: median point (participant·es, habitant·es) is the intended
  convention but the doc mixes ·, . and plain masculine — normalize to median point.
- Feminine role titles for named staff (Chargée, Cheffe de Projet, Directrice).
- Guillemets « » for UI labels and coined terms; feature names capitalized as proper nouns.

## ⚠ Known hazards in the FR doc (fix per proposal)

- **Prospect residue from ≥3 tenders**: Auderghem (intro letter), Ploemeur (demo/training),
  "à compter du 1er février 2025" (pricing). Replace all.
- **Hosting contradiction**: "en France, à Paris" vs a leftover pledge to keep data "au
  sein du Canada" (Québec variant residue). Must fix for any FR tender.
- Untranslated artifact: "Now facteurs clés" in the TOC; legacy citizenlab.co mailtos.
- OWASP table is the 2017 edition; support hours inconsistent (9–18 vs 9–17).
- No dedicated Poll or Volunteering sections — lags the EN master; check master for
  anything newer.
