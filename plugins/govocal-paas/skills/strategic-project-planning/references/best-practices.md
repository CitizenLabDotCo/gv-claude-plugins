# Best-practice setups by platform maturity

Pick the mix that matches the **derived maturity tier**. Each project should anchor a real Go Vocal
case study (Inspiration Hub / project-library-finder) and cascade to a policy objective.

## Starting (new / low-activity platform)
Goal: build the habit, prove value, grow the base. Keep effort low and trust high.
- **Light-touch:** photo contest, themed/year-end poll, event-programming vote.
- **Close-the-loop consultation** on something residents already discussed (strongest trust-builder).
- **Engagement standards reset** (stop over-surveying; shared internal standards).
- Optionally one **survey** on a live policy question.
Cadence: 4–6 projects/year, mostly light, one formal.

## Growing (active platform, expanding departments)
Goal: widen topics and departments, raise input quality.
- **Mapping** (mobility/safety or greening) with AI analysis.
- **Sector survey** (business/associations) with visible follow-through.
- **Youth agenda-setting** (school-year channel) to shift the age mix.
- **Neighbourhood / multi-annual plan** input.
- Keep 1–2 light touchpoints for momentum.
Cadence: 6–10 projects/year, balanced formal/light.

## Advanced (established, high registered base — e.g. Tiger accounts)
Goal: deepen influence, institutionalise participation.
- **Participatory budgeting** (flagship — residents allocate a real envelope).
- **Public-space co-design** on a real development site (design freedom open).
- **Community monitor** (quarterly liveability/trust waves, reportable per area).
- **Citizen proposals** (always-on statutory channel).
- **Close-the-loop** on prior large consultations.
Cadence: 8–14 projects/year, several flagships + always-on channels.

## Cascade tagging
- **policy priority (★):** the strategic plan explicitly names this aim as a priority.
- **mapped for participation (◇):** the plan maps this topic/area for citizen participation.

## Coverage rule
Every strategic initiative (theme) in the plan should have ≥1 project. Flag and fill gaps.

## Reach & objective
Parse a numeric reach per project where credible; sum the conservative–upside range and compare to the
SMART objective's gap (target − baseline). Label On track / Close / Short. Projected reach ≠ unique
people — a scoping signal, not attribution.

## Source priority
1. The city's strategic plan (verbatim priorities, themes).
2. Planhat usage + recent conversations + documents (what the account is actually doing/asking).
3. Meeting notes (Fireflies/Granola) for fresh asks and blockers.
4. Go Vocal Inspiration Hub (Metabase card 3231) for proven, comparable case studies.
