# #we-grow — post structure and parsing

Channel id: `C0634TK3NBD`. Purpose: celebrating new clients, upsells, and renewals. Posts are generated by the Salesforce-for-Slack bot (`U03RFL35T0X`) when a deal is moved to Won.

## Two post flavours

### 🚀 New customer alert
```
:rocket: *Yiha, new customer alert!* :rocket:

*<Opportunity name>* (<Tier> (<version>), <N> months[, <population> inhabitants]) for <amount> <CUR>.

Well done! <@user|Name> :tada::partying_face::moneybag::clap:

*Why did they choose us?* <semicolon-separated reason tags>
*Explanation:* <free text>

*Details:*
<Target|Non-target>, <Master|Upsell>, <Fixed Term|Continuous>, <Tier>
*Duration:*
<N> months, *Start:* <DD Month YYYY>, *End:* <DD Month YYYY>
*Source:* <Inbound|Outbound|Allbound>

<Salesforce opportunity URL>
```

Example observed in the channel:
> *West Oxfordshire District Council 4a* (Premium (New), 12 months, 109 800 inhabitants) for 17 072 GBP.
> *Details:* Target, Master, Continuous, Premium (New)
> *Source:* Inbound
> `https://govocal.lightning.force.com/006Qs00000fLeVvIAK`

### 🔄 Renewal / upsell alert
```
:arrows_counterclockwise: *Whoop whoop, renewal/upsell alert!* :arrows_counterclockwise:

*<Opportunity name>* (<Tier> (<version>), <N> months) for <amount> <CUR>.

Well done! <@user|Name> :clap::moneybag:

*Why did they renew?* <reason tags>
*Explanation:* <free text>

*Details:*
<Target|Non-target>, <Master|Upsell>, <Continuous|Fixed Term|License change>, <Tier>
*Duration:*
<N> months, *Start:* <date>, *End:* <date>
```

> *Details:* Target, Upsell, License change, Premium (New)

## Fields to extract

From each post, pull:

| Field | Source in post | Notes |
|---|---|---|
| `post_type` | Emoji + header | "new" (🚀) vs "renewal_upsell" (🔄) |
| `opportunity_name` | First bold line | Matches `Data-percontract.Contract-name` fuzzily |
| `tier` | First parenthetical | e.g. "Premium (New)", "Standard + (Pre Nov 25)" — maps to `Tier-level` |
| `duration_months` | First parenthetical | Integer |
| `population` | First parenthetical | Only present for "new customer" with local-gov context |
| `amount` | End of first line | Numeric (may contain narrow-space thousand separator `\u202f` or comma decimal) |
| `currency` | End of first line | ISO: EUR, GBP, USD, CAD, DKK, NOK, CLP (non-EUR seen: GBP, CAD, CLP) |
| `owner` | "Well done! @user" | Slack mention, map to a real person |
| `why_chose_us` / `why_renewed` | Reason-tags line | Semicolon-delimited list: Cost-effectiveness, Differentiating features, Recognized participation expertise, Potential for integrations, Userfriendliness, Digitalisation, Other |
| `explanation` | Free-text line | Context |
| `target_flag` | Details line, position 1 | Target / Non-target |
| `contract_type` | Details line, position 2 | Master / Upsell |
| `sub_contract_type` | Details line, position 3 | Continuous / Fixed Term / License change / Add-on |
| `tier_confirm` | Details line, position 4 | Should match `tier` above |
| `start_date` / `end_date` | Duration line | Parse "DD Month YYYY" |
| `source` | Source line | Inbound / Outbound / Allbound |
| `sf_link` | Last URL | `https://govocal.lightning.force.com/<Opportunity ID>` — `006Qs...` is the opportunity id |

## Cadence

- Posts arrive throughout the week as deals are closed.
- Weekly team review is **Monday for the prior week** (Mon 00:00 CET → Sun 23:59 CET).
- This is the window to use when asked "last week's bookings".

## Matching #we-grow posts to DCCI

Primary join: **Salesforce opportunity URL → `Data-percontract.CRM-link`**.

The Salesforce opportunity id (e.g. `006Qs00000fLeVvIAK`) is the canonical key. Extract the id from the URL in the post, then look for a `CRM-link` in `Data-percontract` containing that id.

Fallbacks when CRM-link is missing or malformed:
1. Fuzzy match opportunity name → `Contract-name` (watch out for trailing suffixes like "4a", "5 - Protinus").
2. Match amount + currency + `Date-moved-to-won` within ±1 day.

## What a "missing" DCCI entry means

- The admin team (Jordan H.) hadn't booked it yet by the time of the scan. This is the dominant case.
- Surface it so he can process.

## What a "missing" #we-grow entry means

- The bot didn't fire, or the deal was manually created in DCCI without going through the Won trigger.
- Less common; investigate when it happens.

## Currency reporting

When summarizing #we-grow, report:
- In native currency per post (as people read it in Slack).
- Convert to EUR using `Date-start` FX rate (DCCI already does this in `Value`). If the DCCI row isn't booked yet, use a current-day FX rate as an approximation and flag it.

Non-EUR currencies to expect: GBP (UK), CAD (Canada), USD (US), DKK/NOK (Scandinavia), CLP (Chile), EUR (everything else).
